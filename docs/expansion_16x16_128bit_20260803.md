# SPL-G1 扩容记录：4×4→16×16 + 128-bit 存储（v3, 2026-08-03）

## 目标（用户确认）
- 阵列 4×4 → **16×16**（256 cells）
- 每 cell local_store 64-bit → **128-bit**
- 扩容优先，Materica 近接性约束后续再调（记录在案）

## 容量账
- 旧：4×4 × 64-bit = 16 × 8B = **128 字节**
- 新：16×16 × 128-bit = 256 × 16B = **4096 字节（4KB）**，容量 ×32

## 关键架构决策：audit dep_mask 象限化
16×16=256 cells 的 P-tag 无法塞进 56-bit dep_mask。
方案：4 个 audit unit 各管一个 8×8 象限，象限内 64 cells 的 P-tag[5:0]
XOR 折叠成 14-bit 指纹，4 个象限拼成 56-bit dep_mask。
**有损聚合**——完整 256-bit dep_mask 延后到 Phase A5（NOMOS 约束规则）。
