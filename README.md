## ✦ About

<p style="font-size:15px;line-height:1.8;color:#2C2C2C">SPL-G1 是四合一硬件因果审计管线，统一调度 CPU、GPU、NPU 与持久内存，对计算全过程进行因果级可观测审计。它以 RA-BUS 为核心互联，将异构算力收敛为单一可验证的执行平面，为合规计算与可信 AI 推理提供硬件基石。</p>
